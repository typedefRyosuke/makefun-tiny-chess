A 4 KB Python chess engine (0x88 board, PVS + transposition table + quiescence search, 100k nodes/move) that speaks the make.fun env protocol. Practice gauntlet Elo ~1393 (trial-0: 1364, trial-1: 1451, trial-2: 1364).

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8000 python3 main.py
```
